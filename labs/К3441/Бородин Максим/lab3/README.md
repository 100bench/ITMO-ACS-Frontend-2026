# Лабораторная работа 3 — сервис рецептов на Vue

**Студент:** Бородин Максим, К3441
**Вариант:** 5 — обмен рецептами и кулинарные блоги.

## План реализации

1. Создать отдельное приложение Vue 3 на Vite. Страницы каталога, рецепта, входа, регистрации и профиля оформить маршрутами Vue Router. Сохранить стиль и данные ЛР2.
2. Вынести повторяемые карточки рецептов и шапку в компоненты. Поиск и фильтры оставить в каталоге; страницу рецепта сделать общей для всех шести записей.
3. Подключить axios к отдельному процессу `json-server-auth`. В общем API-клиенте добавлять токен; в `useAuth` хранить состояние входа, в `useTheme` — выбранную светлую или тёмную тему.
4. Перенести действия из ЛР2: регистрация, вход, выход, сохранение, лайки, подписки и комментарии. Профиль показывает сохранённые рецепты и подписки.
5. Проверить `npm run build`, данные и защиту API, маршруты и основные действия в браузере. Код не должен зависеть от DOM-разметки ЛР2.
