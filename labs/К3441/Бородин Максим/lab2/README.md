## План реализации

1. Сохранить страницы ЛР1, вынести рецепты и связанные данные в `db.json`, загружать каталог и детали через `fetch` из локального `json-server`.
2. Подключить `json-server-auth`: регистрация и вход выдают токен; профиль и действия пользователя работают только после входа. Избранное, лайки, подписки и комментарии хранить на сервере с привязкой к пользователю.
3. Показывать состояния загрузки, пустого результата и ошибки. Фильтровать полученный каталог без дополнительных библиотек.
4. Для ДЗ2 улучшить подписи, семантику, сообщения об ошибках и видимый фокус; для ДЗ3 добавить светлую и тёмную темы на CSS-переменных; для ДЗ4 собрать пять иконок в один SVG-спрайт.
5. Установить зависимости и проверить запуск API, HTTP-запросы и основные сценарии в браузере.

## Запуск

В этой папке выполнить `npm install` и `npm start`, затем открыть http://localhost:3000. Данные хранятся в `db.json`. Для Bootstrap и встроенного видео требуется интернет.

## Реализовано

- Все шесть карточек загружаются через `fetch('/recipes')`; каждая открывает свой `recipe.html?id=...` с данными из `GET /recipes/:id`.
- Регистрация и вход обращаются к `/register` и `/login`. Токен и профиль сохраняются в браузере; пароль не записывается в клиентское хранилище. Пароли пользователей в `db.json` создаёт и хеширует `json-server-auth`.
- Избранное, лайки, подписки и комментарии хранятся в серверных коллекциях. Чтение доступно всем, запись и удаление требуют токен; удалять свои записи можно только владельцу.
- Каталог и страницы показывают загрузку, пустой результат и ошибки сети. Профиль требует входа.
- ДЗ2: семантические области, подписи полей, `aria-live`, `aria-pressed`, ссылка пропуска навигации и видимый фокус. ДЗ3: темы на CSS-переменных, переключатель и учёт системной настройки. ДЗ4: пять иконок в `assets/sprite.svg`.

## Проверка

`npm test` проверяет структуру рецептов и правила доступа. Для ручной проверки: открыть карточки разных рецептов; зарегистрироваться и войти; сохранить рецепт, поставить лайк, подписаться и отправить комментарий; обновить страницу и открыть профиль. Запись действия без входа должна переводить на страницу входа.

Это учебное моковое API: `db.json` хранит данные локально. Запускайте сервер только на `127.0.0.1`.
