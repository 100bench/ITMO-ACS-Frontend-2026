# Лабораторная работа 1 — сервис рецептов

**Студент:** Бородин Максим, К3441  
**Вариант:** 5 — сервис для обмена рецептами и кулинарных блогов.

## План реализации

1. Сделать пять страниц: каталог с поиском и фильтрами, вход, регистрация, личный кабинет и подробный рецепт.
2. Разметить страницы семантическим HTML. Для сетки, форм и мобильной навигации использовать Bootstrap, для оформления — один небольшой файл CSS.
3. Добавить простой JavaScript без сборщика: фильтрацию по типу блюда, сложности и ингредиентам; демонстрационные вход и регистрацию; сохранение рецепта, лайк, подписку и комментарии через `localStorage`.
4. Проверить ссылки между страницами, мобильную ширину, обязательные поля и работу интерактивных элементов.

## Запуск

Откройте `index.html` в браузере. Для корректной загрузки Bootstrap и фотографий нужно подключение к интернету. Данные демонстрационные и остаются только в текущем браузере.

## Что работает

- Каталог фильтруется сразу при вводе по названию, типу блюда, сложности и ингредиенту. Кнопка сброса возвращает все карточки.
- Формы входа и регистрации проверяют обязательные поля; регистрация дополнительно сравнивает пароли. В учебном режиме вход принимает любые данные, пароль не сохраняется.
- На странице рецепта можно поставить лайк, сохранить рецепт, подписаться на автора и оставить комментарий. Состояние доступно в профиле и сохраняется в `localStorage`.
- Подробная страница создана для пасты; остальные карточки демонстрируют работу каталога и ведут к похожему рецепту.
